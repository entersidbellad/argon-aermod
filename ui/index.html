      How it was built

      An AI translated EPA's model line by line. Nobody edited its code by hand.

      EPA publishes AERMOD as Fortran, a scientific programming language from the 1950s that few teams can maintain or plug into modern software. Google's Gemini 4 Argon AI model read the source and wrote the Python version. People built the checks; an automatic trace proves no one touched the model code itself.

        About

        Air-permit answers for heavy industry, without the black box

        AERMOD is the model the US EPA requires for estimating how pollution from industrial stacks spreads downwind. A permit application for a new or modified plant runs it over years of weather and compares the result with the federal air-quality limits. This project makes that model fast, modern and auditable, starting with the questions cement plants ask.
