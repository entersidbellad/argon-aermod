How it works

Gemini 4 Argon read the in-scope AERMOD Fortran in one full-context request and wrote the whole Python package. An automated repair loop then fixed divergences against the reference build. Every request is recorded under agent/runs/; the numbers below are read from those records and results/.

Each EPA test case is run through the Python port and through our gfortran build of the original Fortran. harness/compare.py scores the pair under two rules; a case passes only if both hold. The script is frozen: its sha256 is pinned, so the bar cannot move after the results are in.
