Can the Python model be trusted with a permit question? Each EPA test case is run through the Python model and through the original Fortran AERMOD. A case passes only if the Python model's hourly concentrations match the Fortran's within a strict tolerance and its regulatory design value matches at every receptor. The scoring script is frozen (its fingerprint is pinned), so the bar cannot move after the results are in.
